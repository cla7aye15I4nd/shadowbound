# nginx-tests files that fail under ShadowBound but pass natively, with nginx
# 1.31.6 built with -flto. test/nginx/run.sh fails CI only on failures NOT
# listed here, and reports listed files that now pass (delete those lines).
#
# Known cause: these files make nginx build a pointer a few bytes BEFORE the
# start of a heap object (offsets -1..-16 observed). ShadowBound checks a
# pointer when it is created, and while the allocator keeps 32 reserved bytes
# after every object (so one-past-the-end pointers are fine), there is no such
# reserve before an object, so the lower-bound check fires. Examples:
#   ngx_http_alloc_large_header_buffer: `new + (r->field - old)` with a field
#     2 bytes before `old`, stored into the request;
#   ngx_resolve_name_locked / ngx_http_sub_body_filter: start-1 / start-8.
# These are false positives (the pointer is never dereferenced out of bounds).
